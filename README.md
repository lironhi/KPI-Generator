# KPI Generator

## Description
KPI Generator is a simple tool designed to generate graphs from CSV files to visualize key performance indicators (KPIs) of sales agents.

## Features
- Select multiple CSV files.
- Generate customized graphs for each file.
- Automatically save the graphs as PNG files.

## Requirements
No prerequisites are needed to use this software. The executable includes everything required.

## Installation
1. Download the Folder (`KpiGenerator`) and the files.
2. Run the .exe.

## Usage
1. Double-click on `KpiGenerator.exe` to launch the application.
2. Click on the file selection area to browse and select CSV files.
3. Once files are selected, click the `Apply` button to process the files.
4. The generated graphs will be saved in the same directory as the executable.

## Notes
- Ensure that the CSV files follow the required structure for accurate graph generation.
- The software may take a few seconds to launch due to its single-file setup.
